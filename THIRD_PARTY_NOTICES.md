## face-api.js and included model files

This project includes `public/static/vendor/face-api.min.js` and local face model files in `public/static/models/`.

- Project: [face-api.js](https://github.com/justadudewhohacks/face-api.js)
- Copyright: Vincent Mühler
- License: MIT
- Full license text: `public/static/vendor/face-api-LICENSE.txt`

The included Tiny Face Detector, Tiny Face Landmark 68, and Face Recognition models run locally in the browser. They create a descriptor from one registered front-facing face capture and compare it with a live camera descriptor for automatic attendance matching. No cloud face-recognition API is used.
